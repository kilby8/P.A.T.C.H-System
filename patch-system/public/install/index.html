Get the app

The player HUD and GM console, on your home screen. It's free, there's no app store or sign-up, and it opens without signal once it's installed.

You're all set. P.A.T.C.H. is installed on this device.

Your browser can install it right now.

Android

Web app (updates itself)

  1. Open this page in Chrome.
  2. Tap ⋮ at the top right.
  3. Tap Install app (or Add to Home screen), then Install.

Or download the Android app

The full Android build from GitHub. Android will ask you to allow installs from Chrome the first time.

Download APK

iPhone & iPad

  1. Open this page in Safari.
  2. Tap Share (the square with the arrow).
  3. Tap Add to Home Screen, then Add.

Computer

  1. Open this page in Chrome or Edge.
  2. Click the install icon at the right end of the address bar, or the ⋮ menu → Install P.A.T.C.H.

Or just use it in the browser at the main page.

Don't see the install option? Open the link in Chrome (Android) or Safari (iPhone) rather than inside another app's browser, like Discord or a text-message preview. Use "Open in browser" first.
